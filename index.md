## Course Description
Welcome to **Neuro By the Numbers**, a course focused on quantitative neuroscience, computational methods, and the principles behind neural data analysis. This class is designed for students interested in understanding how numerical and analytical tools are used to study the brain.

## Course Structure
- Weekly lectures covering theory and applications  
- Hands-on coding exercises (Python / Jupyter)  
- Paper discussions  
- Homework assignments and optional mini-projects  
- Downloadable notes and materials hosted on this site

Software requirements, readings, communication policies, and other course logistics will be posted here throughout the term.
